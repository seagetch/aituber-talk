# ナイルの恵みとエジプト文明の夜明け  
![ナイル川の夕景](https://upload.wikimedia.org/wikipedia/commons/c/cb/Nile_Sunset.JPG)  
こんにちは～都会派タヌキ耳VTuber、Midoriだよ！ナイル川の夕焼け、すごくキレイだよね。この川が毎年氾濫して運んでくる黒い土が、古代エジプトの人びとの命綱だったんだって。水が引いた後の畑には豊穣の大地が広がって、作物もご機嫌に育ったんだよ。そんな豊かな自然のリズムから、暦や祈りが生まれて、やがて「ファラオ」と呼ばれる王様たちの物語が始まったの。今日は私と一緒に、約3000年の歴史を10ステップで旅してみよう！では、ナイルのささやきに耳を澄ませて、LET’S GO☆  

# 階段ピラミッドと古王国のスタートダッシュ  
![階段ピラミッド](https://upload.wikimedia.org/wikipedia/commons/thumb/7/75/Pyramid_of_Djoser_%28Step_Pyramid%29_%2814613620207%29.jpg/960px-Pyramid_of_Djoser_%28Step_Pyramid%29_%2814613620207%29.jpg)  
紀元前27世紀、第3王朝のファラオ・ジョセル王がデビュー！彼は自分の墓に「階段ピラミッド」をチョイス。段々畑みたいに積み重ねられた六段の石が天空へ続く階段みたいで、本当にワクワクするデザインだよね。設計したのは建築界のスーパーエンジニア、イムホテプさん。王様の「天まで届け！」って熱い想いが、石の階段にギュギュッと詰まってる感じ。きっと建設現場は「次はどの石を置く～？」って職人さんたちがキャッキャしてたはず。私も混ざって、つい「もっと左、もっと左！」なんてアドバイスしちゃいそう（笑）。  

# クフ王の大ピラミッドとギザ砂漠の巨石パーティ  
![ギザの大ピラミッド](https://upload.wikimedia.org/wikipedia/commons/e/e3/Kheops-Pyramid.jpg)  
お次は古王国第4王朝のスーパースター、クフ王！彼はギザに高さ約146メートル、地上50階建て並みのビックプロジェクト「大ピラミッド」をドーンと建造。農閑期の農民さんたちがワイワイ参加して、200万個以上の巨石を積み上げたんだって。想像してみて、週末のBBQみたいにお祭り気分で集まったんじゃないかな？「この石はアゴが疲れる～」とか言いながらも、団結力抜群！ピラミッドは「王の威光見てみて～！」のステータスシンボルでもあったから、みんな気合十分だったんだろうな。  

# 古王国の黄昏とウナス王の小さな呟き  
![ウナス王のピラミッド跡](https://upload.wikimedia.org/wikipedia/commons/thumb/f/f6/26651-_Pyramid_of_Unas.jpg/960px-26651-_Pyramid_of_Unas.jpg)  
でもね、どんなゴージャスも永遠じゃない。第5王朝のウナス王のピラミッドは、ちょっぴり気の毒なことに崩れ落ちて、今は砂に埋もれがち…だけど内部に「ピラミッド・テキスト」っていう魔法の呪文みたいな文字が初めて刻まれたんだって！来世への案内書みたいで、不安と期待が入り混じった心情が伝わってくるよね。ウナス王は「これで安心してあの世へ…」って小さく呟いたかも。歴史の片隅で、王様の震える声が聞こえてきそうだよ。  

# 中王国の再起動 – メンチュヘテプ２世とテラス神殿  
![メンチュヘテプ２世葬祭殿](https://upload.wikimedia.org/wikipedia/commons/thumb/5/57/Temple_of_Mentuhotep_at_Deir_el-Bahri_%28I%29_%288030674872%29.jpg/960px-Temple_of_Mentuhotep_at_Deir_el-Bahri_%28I%29_%288030674872%29.jpg)  
第一中間期のバタバタを乗り越え、紀元前21世紀末に再びひとつになったのが第11王朝のメンチュヘテプ2世。彼はテーベの岩山に、段々畑のようなテラス神殿を建てて「エジプト、再スタート！」を宣言したんだよ。石の柱と自然の岩壁がうまくマッチしてて、まるで都会の高級テラス席みたい。ここで「またみんなでワイワイやろうね～」って宴会開いたら楽しそうだよね！  

# セヌスルト３世 – リアルすぎる王の肖像とヌビア遠征  
![セヌスルト３世頭部像](https://upload.wikimedia.org/wikipedia/commons/thumb/f/f9/Head_of_King_Senusret_III_in_Gulbenkian_Museum.JPG/960px-Head_of_King_Senusret_III_in_Gulbenkian_Museum.JPG)  
続いて第12王朝、ガチでタフな王様、セヌスルト３世の登場！彼はヌビア遠征で国境をグイッと拡大し、地方豪族をバシッと抑えた強力リーダー。そんな王の像が超写実的だからビックリ！眉間のシワまでバッチリ再現されていて、「今日も頑張ったなぁ…」って疲れた顔してるの。政治も戦も大変だったんだろうなぁ。王の苦悩まで感じる、まさに中王国芸術の頂点です。  

# ハトシェプスト女王 – ガールズパワー全開の平和外交  
![ハトシェプスト葬祭殿](https://upload.wikimedia.org/wikipedia/commons/thumb/5/56/Temple_of_Hatshepsut.jpg/960px-Temple_of_Hatshepsut.jpg)  
新王国のヒロインといえば、やっぱりハトシェプスト女王！最初は継子トトメス3世の摂政だったけど、自らがファラオに。男性装束でキメキメの姿を彫像に写して「女でもできるんだから！」って女の子たちに勇気をくれたんだよ。紅海の向こうのプント遠征では、香料や黄金、珍しい香木をいっぱい持って帰ってきたって…おしゃれ女子のバイヤーみたい！神殿のテラスはキラキラで、女王の“センス良すぎ”っぷりに私も憧れちゃう。  

# アマルナ革命 – アクエンアテンのぶっ飛び一神教  
![アクエンアテン浮彫](https://upload.wikimedia.org/wikipedia/commons/thumb/e/e8/Relief_of_Akhenaten_from_Amarna%2C_ca._1340_BCE%3B_Pergamon_Museum%2C_Berlin_%2839513435674%29.jpg/960px-Relief_of_Akhenaten_from_Amarna%2C_ca._1340_BCE%3B_Pergamon_Museum%2C_Berlin_%2839513435674%29.jpg)  
ドラマティック枠突入！第18王朝のアクエンアテンは、従来の神々をぜーんぶお休みさせて太陽円盤アテンだけ信じる一神教にチェンジ。新首都アマルナを砂漠に作って、壁画も家族ポートレートみたいに親しみやすいスタイルに一新。「うちの王様、こんなにオシャレだったんだ！」って当時もSNSで話題になったはず（笑）。でも改革が急すぎて民衆が戸惑ったらしく…17年後にはまた元の多神教に戻っちゃう。まるで一発ネタの期間限定ショップみたいだね。  

# ツタンカーメン – 少年王と黄金のタイムカプセル  
![ツタンカーメン黄金マスク](https://upload.wikimedia.org/wikipedia/commons/thumb/6/6f/CairoEgMuseumTaaMask.jpg/500px-CairoEgMuseumTaaMask.jpg)  
次は「墓だけ有名」伝説の主人公、ツタンカーメン王！9歳で即位して19歳でお別れしちゃった短命王だけど、1922年に発見された黄金のマスクが超ド派手で「うわぁ！」ってなったよね。墓の中はほぼ手つかずで、埋葬品がそのままタイムカプセル。戦車だの宝石だの、豪華すぎる埋葬グッズ大集合！発掘チームも思わず「キャー！」って悲鳴を上げたとか。歴史って、本当にロマンだね。  

# アブ・シンベル大神殿 – ラムセス2世のラストファンタジー  
![アブ・シンベル大神殿](https://upload.wikimedia.org/wikipedia/commons/thumb/2/23/Abu_Simbel_temples.JPG/960px-Abu_Simbel_temples.JPG)  
ついにフィナーレ、新王国の大帝ラムセス2世！彼はカデシュの戦いで戦勝自慢しまくり、お城じゃなくてヌビアの岩山をくり抜いて **アブ・シンベル大神殿** をDIY。高さ20mの自画像を４体も並べて「私、ここにいるよ！」ってアピール。ちなみに1960年代、アスワン・ハイダムで水没するピンチになったとき、国際協力でそっくりそのまま移築したんだって。王様の威光と現代の技術がミックスされた最高のコラボだよね。
