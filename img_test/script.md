# 1. 宇宙に特別な向きはない？

![star_trails](https://upload.wikimedia.org/wikipedia/commons/thumb/f/f2/International_Space_Station_star_trails_-_JSC2012E039800.jpg/960px-International_Space_Station_star_trails_-_JSC2012E039800.jpg)

夜空の星が大きな円を描くように写っているのは、地球が自転しているからです。  
同じ理屈で「もし宇宙全体が回転していれば、どこかに軸が見えるはず」と考えられます。ところが宇宙マイクロ波背景放射を精密に測っても、温度は全方向でほぼ同じ。これを **宇宙の等方性** と呼び、現行の標準モデルは「宇宙には特別な向きがなく、回転もしていない」という前提で成り立っています。今日の話は、その大前提をあえて疑ってみるところから始まります。では、なぜわざわざそんな大胆な仮説を持ち出すのでしょうか。

# 2. 銀河も回転している

![andromeda](https://upload.wikimedia.org/wikipedia/commons/thumb/9/98/Andromeda_Galaxy_%28with_h-alpha%29.jpg/960px-Andromeda_Galaxy_%28with_h-alpha%29.jpg)

ここに写っているアンドロメダ銀河は、直径が二十万光年を超える巨大な渦巻き構造です。  
内部の星やガスは二億年以上かけて銀河中心を一周しています。実は、私たちが住む天の川銀河も同じくらいの周期で回転中です。**回ること自体は宇宙で極めて一般的な現象** といえるわけです。いっぽう銀河を外から眺めると、星々は「遠心力で外へ飛び出すはずなのに、しっかりまとまっている」という不思議な振る舞いを示します。これが次のスライドで紹介する「銀河回転曲線の謎」につながります。

# 3. 銀河回転曲線の謎

![rotation_curve](https://upload.wikimedia.org/wikipedia/commons/thumb/c/cd/Rotation_curve_of_spiral_galaxy_Messier_33_%28Triangulum%29.png/960px-Rotation_curve_of_spiral_galaxy_Messier_33_%28Triangulum%29.png)

グラフの破線は「見えている星とガス」の質量だけで計算した公転速度です。中心から離れるほど速度は下がるはず――ところが実測値（実線）は外側までほぼ一定。  
天文学者はこの差を **ダークマター** で埋めました。「暗いハロー」が銀河を包み込み、追加の重力を供給している、と考えたのです。ところがダークマターは直接検出できず、性質も正体も不明なまま。ここで「もしかすると銀河を取り巻く追加の力は、宇宙そのものの回転という大局的な効果かもしれない」という別ルートが浮上します。

# 4. 加速膨張する宇宙

![expansion_timeline](https://upload.wikimedia.org/wikipedia/commons/thumb/6/6f/CMB_Timeline300_no_WMAP.jpg/960px-CMB_Timeline300_no_WMAP.jpg)

1998 年、遠方の超新星観測から「宇宙の膨張が減速ではなく**加速**している」ことが分かりました。  
その原因として導入されたダークエネルギーは、宇宙全体の７割を占めるとされますが、こちらも物理的実体は謎です。  
もし宇宙がわずかに回転していれば、時空そのものが“遠心的に押し広げられる”ため、膨張を後押しする効果が生じます。つまり **宇宙回転はダークエネルギーの代役** を果たしうるわけです。この視点は、私たちが抱える二つの暗黒問題を同時に照らし出します。

# 5. 膨張率が合わない――ハッブルテンション

![hubble_tension](https://astrobites.org/wp-content/uploads/2025/04/figure1-1024x443.png)

宇宙の膨張速度、いわゆる **ハッブル定数** を測る方法は二種類あります。  
(1) 近傍の変光星や超新星を使って“今”の膨張を測る手法はおよそ七十三キロ毎秒毎メガパーセク。  
(2) 宇宙マイクロ波背景放射の揺らぎから“昔”を推定しモデル計算で現在値を出すと約六十七。  
どちらも観測精度は上がるのに、値は歩み寄りません。これを **ハッブルテンション** と呼びます。2025 年の研究では「宇宙が五千億年に一回転の超低速で自転していれば、この食い違いを自然に説明できる」と提案されました。膨張と回転が少しずつ相互作用し、時代によって見かけの膨張率がずれるというのです。 [oai_citation:0‡Phys.org](https://phys.org/news/2025-04-slowly-universe-hubble-tension.html?utm_source=chatgpt.com)

# 6. 宇宙がゆっくり回転していたら？

![spiral_diagram](https://cdn.mos.cms.futurecdn.net/RTaeh3E7MbiPpnEWy5J6Pf-650-80.png.webp)

仮に宇宙が **十のマイナス十八乗ラジアン毎秒**、つまり五千億年で一周という極めて遅い速度で回っているとします。  
この“ほぼ止まっている”ような回転でも、宇宙サイズでは遠心効果が効いてきます。遠心力は中心から遠いほど強く働くため、遠方銀河の膨張をわずかに加速させ、近傍と遠方の膨張率を変化させます。結果として先ほどのハッブルテンションが解消される、というのが最新モデルの要点です。もちろん回転が速すぎると宇宙背景放射の均一性と食い違うため、“許されるのは極小の回転” という条件が付きます。 [oai_citation:1‡アーススカイ](https://earthsky.org/space/universe-spinning-study-hubble-tension/?utm_source=chatgpt.com)

# 7. 銀河回転曲線を遠心力で説明

![spiral_effect](https://chatgpt.com/9fa25ea5-596c-4b8a-9d58-77f6001f04de)

同じ回転宇宙モデルを銀河スケールに適用するとどうなるでしょう。  
宇宙全体の回転で生じる巨大な慣性フレームの「引きずり効果」が、銀河円盤の外側をそっと持ち上げる役目を果たします。  
実際、アンドロメダ銀河や M81 の回転曲線は、見かけの遠心力を足し合わせるだけで再現できる、というシミュレーションが 2024 年に報告されています。  
この理論が正しければ、銀河を包むダークマター・ハローは必要なくなります。つまり「暗黒物質の正体探し」から「宇宙フレームの動きを測る」へと、研究の焦点が大きくシフトする可能性があるのです。 [oai_citation:2‡ScienceDaily](https://www.sciencedaily.com/releases/2024/06/240617173533.htm?utm_source=chatgpt.com)

# 8. JWST が見た銀河の並び

![jwst_deep_field](https://upload.wikimedia.org/wikipedia/commons/thumb/b/bf/Webb%27s_First_Deep_Field.jpg/1003px-Webb%27s_First_Deep_Field.jpg)

最新の深宇宙観測では、遠方約百三十億光年に散らばる二百六十三個の銀河の“回転方向”を統計的に分類したところ、三分の二が同じ向きに回っているように見えました。  
もし偶然なら確率は一億分の一以下。観測バイアスの可能性も議論されますが、「生まれたばかりの宇宙に初期回転があった」シナリオとも整合的です。  
将来の望遠鏡はさらに広い空を同じ手法で調べ、回転方向の偏りが本物かどうかを判定していきます。ここが証拠集めの第一歩です。 [oai_citation:3‡アーススカイ](https://earthsky.org/space/universe-spinning-study-hubble-tension/?utm_source=chatgpt.com)

# 9. それでも「ほぼ」等方な宇宙

![cmb_map](https://upload.wikimedia.org/wikipedia/commons/thumb/5/56/Baby_Universe.jpg/960px-Baby_Universe.jpg)

こちらは宇宙マイクロ波背景放射の全天マップ。色のムラは温度の差ですが、その振れ幅は十万分の一程度しかありません。  
この均一さは「宇宙が激しく回っていたら到底保てない」ため、回転モデルはきわめて厳しい上限を守らざるを得ません。  
プランク衛星の解析では「宇宙が回転している証拠は統計的にほぼゼロ」とも報告されました。  
ただし自転速度が十分に小さければ観測網をすり抜け得る――これが回転宇宙派の主張です。つまり今後の超高精度測定が、モデルを生き残らせるか否定するかの決め手になります。

# 10. まとめ ― 回転宇宙は何をもたらすか

![cosmic_web](https://upload.wikimedia.org/wikipedia/commons/thumb/1/1f/Illustris_dark_matter_structure_at_z=0.png/960px-Illustris_dark_matter_structure_at_z=0.png)

  1. 銀河回転曲線  
  2. ハッブルテンション  
  3. 加速膨張  
  ――三つの難題を一手に説明できる。  
* 観測上の制限は厳しく、許される速度は「五千億年で一回転」以下。  
* 今後は CMB 偏光、銀河の回転方向統計、重力波背景など多方面から検証へ。  

暗黒物質も暗黒エネルギーも「宇宙回転」という一見単純なアイデアで置き換えられるかもしれない――しかし証明には精密観測と理論の両輪が必須です。  
“宇宙は本当に回っているのか？” その答えが出る日は、私たちが宇宙を理解する枠組みそのものが塗り替わる日になるでしょう。
